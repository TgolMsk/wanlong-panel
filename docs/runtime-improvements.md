# 运行可靠性与模板识别完善

2026-09-15，落实项目审查中的五项改进。

## 1. 暂停自动调度

- 关闭自动会取消当前自动执行链。采样返回后、派遣取得实例锁后都检查取消状态。
- 重新开启时使用新的取消信号，旧采样即使随后返回也不能进入新的派遣周期。
- 取消信号贯穿采集、采样、冷启动恢复及 AI 恢复的设备操作。用户主动取消不累计为采样故障。
- 已派出队伍仍保存统计和行军记录；取消后的记账不会再启动面板采样。
- 正在执行的设备操作收尾期间显示状态，并禁用重复手动采样。

已经交给 ADB 的单条命令或连点批次可能执行完；取消会阻止后续命令，不能撤销游戏里已经完成的点击。

## 2. 任务互斥

脚本、调度采样、自动派遣、使用调度独占入口的机器人动作共用主进程实例占用表。脚本在首次异步等待前预占实例与并发名额，启动失败释放；成功启动后，直到执行进程退出才释放。

同一实例已有操作时，脚本启动会给出占用提示。不同实例仍可并行运行。调度内部的串行队列保留，派遣中的记账回调可以重入，避免锁内互相等待。

## 3. 模板制作使用无损 PNG

“高级工具 → 模板库”的主帧和差分帧改走 `device:capturePng`，从原始 RGBA 截图直接编码 PNG；默认保持原始分辨率。选择缩小尺寸时，仍使用无损 PNG 编码，但缩放本身会改变像素。

模板保存、差分去底和预览使用同一份 PNG 数据。常规画面预览继续使用 JPEG。现有模板无需转换，已有 JPEG 来源模板的细节只有重新抓取才能恢复。

## 4. 透明数字模板兼容

多峰匹配 `matchAllInCrop` 现在使用 `PreparedTemplate.mask`，可寻找同一透明字形的多次出现。增加掩码长度与全透明校验，并过滤非有限分数和明显超出归一化范围的分数。

本次补齐匹配能力，未批量修改字形模板；模板编译原有的低方差、覆盖率、最少有效像素保护继续生效。

## 5. 设置切换与数据保存

### 重启后生效的设置

模拟器种类、ADB 路径、管理程序路径、数据根目录、参考分辨率在下次启动生效。表单展示已保存值，运行中的设备操作与文件路径保持本次启动的值；设置页提示是否需要重启。其它普通设置即时生效。

数据根目录可直接输入完整绝对路径。保存时先验证设备数据标记并准备目录；失败会报告错误，保持原运行配置。数据目录切换会打开目标目录中的数据，不自动搬迁原文件。

### 模拟器身份隔离

数据根目录中的 `device-context.json` 记录首次使用该目录的模拟器身份。身份由模拟器种类和管理程序完整路径计算。

```text
<用户选择的数据根目录>/
  device-context.json
  templates/                  同一根目录内共享
  scripts/                    同一根目录内共享
  accounts/、scheduler.json…   首次使用该根目录的模拟器数据
  emulators/<种类-身份摘要>/    其它模拟器安装各自的数据
    accounts/
    scheduler.json
    gather-state.json
    alerts-pauses.json
    stats/、shots/、logs/…
```

首次升级保留当前数据及自动开关。切换到另一套模拟器安装时不会继承原账号绑定、自动开关、暂停或队列；切回原安装恢复原数据。通知和 AI 配置也随各自运行数据目录保存，新环境按需配置。

同一安装下删除并重建相同序号的模拟器实例，仍需核对账号绑定；目前身份隔离覆盖模拟器种类与安装路径，没有引入每台虚拟机的永久 UUID。

### 并发保存

`gather-state.json` 的读改写按文件串行执行，写入前复制本次状态，使用唯一临时文件并原子替换。读取损坏 JSON 时保留原文件并报错，避免把它当成空记录覆盖其它实例。设置保存也已串行化，且只在落盘成功后更新内存设置。
